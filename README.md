## Smooth Coastlines ##
The code part of [Terra Prety](https://mods.vintagestory.at/terraprety), a world generation mod for Vintage Story.

## Map preview ##
`TerraPrety.Preview` is a standalone CLI that renders a PNG preview of the generated world for a seed and world settings. See [TerraPrety.Preview/README.md](TerraPrety.Preview/README.md).
